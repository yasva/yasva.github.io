## Security pipeline
Every pull request and push runs a reusable "secure-by-default" GitHub Actions
workflow: secret scanning (gitleaks), SAST (Semgrep), dependency and container
scanning (Trivy) and an SBOM (Syft). How it works, the trade-offs, and a short
threat model for AI agents with MCP tools: [`security/`](security/README.md).
